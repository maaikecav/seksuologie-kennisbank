# Signaleringsplan (eigen materiaal)

## Kort overzicht

Een invulbaar vroegsignaleringsformulier (vergelijkbaar met een Wellness Recovery Action Plan/WRAP-achtige aanpak) waarin een cliënt per fase — van "ik voel me goed" tot "crisis" — in kaart brengt welke signalen bij zichzelf en bij anderen optreden, en wat er zelf en door anderen gedaan kan worden. Bruikbaar bij cliënten met een geschiedenis van stemmingsschommelingen, trauma-gerelateerde ontregeling, of andere klachten waarbij vroege herkenning van opbouwende spanning het verschil maakt tussen tijdig bijsturen en escalatie.

## Uitgebreide uitleg

### Doel

Vroege signalen van toenemende ontregeling herkenbaar en bespreekbaar maken — voor de cliënt zelf én voor naasten — zodat er eerder en gerichter bijgestuurd kan worden, in plaats van pas te reageren wanneer een crisis al aan de gang is.

### Voor wie / in welke situatie geschikt

Cliënten bij wie stemmings- of spanningsschommelingen een rol spelen in de klachten (bijvoorbeeld interfererend met seksueel functioneren of relationele stabiliteit), cliënten met een traumageschiedenis waarbij ontregeling herkenbare fasen kent (zie [[Traumabehandeling - EMDR, TF-CBT, NET en fasegerichte aanpak]]), of bredere GGZ-context waarin een signaleringsplan al gangbaar is en seksuologische zorg hierop kan aansluiten.

### Opbouw van het formulier

Het plan bestaat uit vier fasen, elk met dezelfde vijf invulkolommen:

| Fase | Wat merk ik aan mezelf? | Wat merken anderen aan mij? | Wat kan ik zelf doen? | Wat kunnen anderen daaraan doen? | Welke emotie voel ik? |
|---|---|---|---|---|---|
| **Fase 0** — Ik voel me goed | | | | | |
| **Fase 1** — Ik voel me minder goed | | | | | |
| **Fase 2** — Ik voel me niet goed | | | | | |
| **Fase 3** — Ik voel me totaal niet goed / crisis | | | | | |

De laatste kolom ("welke emotie voel ik") kan concreet ingevuld worden met behulp van een emotieregistratie-app (in het oorspronkelijke materiaal: de "How We Feel"-app) — dit ondersteunt cliënten die moeite hebben om emoties spontaan te benoemen met een gestructureerde woordenlijst/emotiewiel.

### Hoe te gebruiken

1. Laat de cliënt (het liefst samen met een naaste/partner, indien van toepassing) de kolommen invullen, te beginnen bij fase 0 (het herkenbare "goede" basisniveau) — dit geeft een concreet referentiepunt.
2. Vul per fase in wat er specifiek verandert: bij zichzelf (bv. slechter slapen, prikkelbaarder, teruggetrokken), wat anderen opmerken (bv. stiller, korter lontje), wat de cliënt zelf kan doen (bv. eerder gaan slapen, contact zoeken, activiteit afbouwen) en wat naasten kunnen doen (bv. er zijn zonder oplossingen aan te dragen, concrete taken overnemen).
3. Bespreek het ingevulde plan met eventuele naasten zodat zij de signalen herkennen en weten wat gevraagd/nodig is.
4. Herzie het plan periodiek — signalen en behoeften kunnen verschuiven na verloop van tijd of na een crisis-ervaring.

### Aandachtspunten en valkuilen

- Het plan is alleen waardevol als het **samen met de cliënt** wordt ingevuld, niet vooraf ingevuld door de behandelaar — de cliënt is de expert van de eigen signalen.
- Betrek waar mogelijk een naaste/partner bij het invullen van de kolom "wat merken anderen aan mij" — dit vraagt soms een apart gesprek, omdat de cliënt zelf de eigen signalen niet altijd (h)erkent.
- Fase 3 (crisis) vraagt aandacht voor concrete, direct uitvoerbare stappen (wie bel je, welke afspraken zijn er met de behandelaar/huisarts/crisisdienst) — dit onderdeel dient niet vaag te blijven.
- Een signaleringsplan vervangt geen individueel veiligheidsplan bij suïcidaliteit; combineer waar nodig met een specifiek veiligheidsplan en de reguliere crisisafspraken binnen de behandeling.

### Contra-indicaties

Geen — wel is een zekere mate van zelfreflectief vermogen nodig om de kolommen zinvol in te vullen; bij ernstige acute crisis is dit niet het moment om het plan (opnieuw) op te stellen, maar om het reeds bestaande plan te raadplegen/toe te passen.
