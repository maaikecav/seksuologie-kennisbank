# HW - Het dagboek bij een drang

> [!info] In het kort
> **Voor wie:** wie wil begrijpen wat er gebeurt bij een sterke drang. · **Doel:** situaties, gedachten en gevoelens bij een drang zichtbaar maken. · **Tijd:** twee weken. · **Nodig:** het schema hieronder.

## Zo doe je het
Schrijf bij elke drang op:

| Datum | Situatie | Gedachte | Gevoel | Lichaam | Wat deed ik? | Wat had ik anders kunnen denken of doen? |
|---|---|---|---|---|---|---|
| | | | | | | |

### Let op denkfouten
Veel mensen merken bij een drang gedachten als:
- "Eén keer kan geen kwaad."
- "Ik heb het verdiend na zo'n dag."
- "Het maakt toch niet uit, ik heb het al verpest."
- "Niemand komt erachter."
Schrijf ze op als je ze herkent, en zet er een eerlijkere gedachte naast.
