# HW - Het afsprakenpapier

> [!info] In het kort
> **Voor wie:** stellen die een open relatie willen beginnen of hun afspraken willen herzien. · **Doel:** duidelijke, gedeelde afspraken op papier. · **Tijd:** een uur. · **Nodig:** het schema hieronder.

## Zo doe je het
Bespreek samen, en schrijf op:

| Onderwerp | Onze afspraak |
|---|---|
| **Wat** mag er met anderen? (flirten, zoenen, seks, daten, verliefd worden) | |
| **Met wie** wel en niet? (vrienden, collega's, exen) | |
| **Waar**? (thuis, in ons bed, op reis) | |
| **Hoe vaak**? | |
| **Wat vertellen we elkaar**, en wanneer? (vooraf, achteraf, details of niet) | |
| **Veilige seks**: condooms, testen, PrEP | |
| **Wat doen we** als een van ons verliefd wordt? | |
| **Wat doen we** als het een van ons te veel wordt? | |
| **Hoe stoppen we**, als dat nodig is? | |

Plan een datum om het te evalueren (bijvoorbeeld over een maand, zie [[HW - De afstemmingssessie]]).

> [!note]- Voor de therapeut
> - **Inzetten bij:** open relaties, en na ontrouw als stellen nieuwe afspraken maken (zie ook [[HW - Ons trouwverdrag]]).
> - **Bron:** Labriola, Fern, Lev & Nichols.
