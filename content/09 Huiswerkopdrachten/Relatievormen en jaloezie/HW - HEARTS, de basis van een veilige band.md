# HW - HEARTS, de basis van een veilige band

> [!info] In het kort
> **Voor wie:** stellen die een open relatie overwegen of hebben, en iedereen die de band wil versterken. · **Doel:** zien wat jullie al doen voor een veilige band, en wat beter kan. · **Tijd:** 45 minuten. · **Nodig:** het schema hieronder.

## Waarom deze oefening?
Jessica Fern beschrijft wat mensen nodig hebben om zich veilig gehecht te voelen, ook als er meerdere relaties zijn. Ze vat het samen in HEARTS. Je hoeft niet alles perfect te doen, maar als deze dingen in het hart van je relatie staan, groeit de veiligheid. Een veilige basis is ook de beste bescherming tegen jaloezie.

## HEARTS
- **H — Hier zijn.** Echt aanwezig zijn, met je aandacht, niet met je telefoon of je gedachten bij iemand anders.
- **E — Laten merken dat je blij bent met de ander.** Niet om wat de ander doet, maar om wie de ander is. Met woorden, aanraking, een blik.
- **A — Afstemmen.** Aanvoelen wat de ander nodig heeft, en daarop reageren.
- **R — Rituelen en gewoontes.** Vaste momenten die houvast geven (zie [[HW - Het thuiskomritueel]]).
- **T — Toenadering na een conflict.** Na een ruzie weer naar elkaar toe bewegen, en herstellen.
- **S — Een veilige band met jezelf.** Jezelf kunnen troosten en geruststellen (zie [[HW - Jezelf troosten]]).

## Zo doe je het
### Stap 1 — Ieder apart
Geef bij elke letter een cijfer (0-10): hoe goed lukt het mij? En hoe goed lukt het mijn partner?

| | Bij mij (0-10) | Bij mijn partner (0-10) | Wat zou helpen? |
|---|---|---|---|
| H — Hier zijn | | | |
| E — Blijdschap laten merken | | | |
| A — Afstemmen | | | |
| R — Rituelen | | | |
| T — Toenadering na conflict | | | |
| S — Band met mezelf | | | |

### Stap 2 — Reflectie (bij H en E)
- Hoe weet ik dat iemand echt bij me is? Wat doet die persoon dan?
- Hoe voel ik me als iemand afgeleid is?
- Hoe merk ik dat iemand blij met me is?

### Stap 3 — Samen
Vergelijk. Kies samen één letter om de komende tijd aan te werken, en één eerste stap.
